AC5-b Dashboard Summary is responsive and exposes filtering + sorting + pagination
Executed 2026-08-14 (dev live).

## Structure (DOM audit)

Dashboard has 2 tabs (WAI-ARIA compliant tablist):
  · role="tablist" aria-label="Dashboard views"
  · role="tab" "Summary"   (default selected)
  · role="tab" "Responses"
  · role="tabpanel" per tab

## Summary tab filters (region "Dashboard filters")

Filters visible:
  · From date (textbox)
  · To date (textbox)
  · Organization (combobox with dev orgs: All / Auctifera / VNFP)
  · Metric (combobox: All / NPS / CSAT)
  · Group by (combobox: Subject / Product)
  · Product (combobox: All products / Rentals)
  · [Apply] and [Clear] buttons

Persistence: current tab is stored in the URL as `?tab=summary` or `?tab=responses`
— survives page reload and enables sharing links to a specific view.

## Summary content sections

Every section rendered as a semantic region/heading with numeric definitions:
  · "Performance overview" — Responses/NPS/CSAT/Needs-review counts
  · "Weekly trends" — Response volume + NPS + CSAT (each a region with img trend)
  · "Subjects" table — Subject, Responses, NPS, CSAT columns
  · "Score distribution" — NPS categories (Detractors/Passives/Promoters) + CSAT (Satisfied/Below threshold)
  · "Response quality" — With additional detail % + approved/pending/flagged/rejected/spam counts

## Export

- "Export insights" button (visible in Summary tab header)
- "Export responses" button (visible in Summary tab header)
- "Export CSV" button (visible in Responses tab — covered in scenario-7)

## Responsive layout

- Root container `.mx-auto .max-w-6xl .px-3 .py-4 .sm:px-4 .sm:py-8`
- Table wrapped in `overflow-x-auto` so wide tables scroll inside their region,
  not the body.
- Flex containers use `flex-col gap-3 sm:flex-row sm:items-center sm:justify-between`
  — collapse to a single column on mobile, spread on ≥sm.
