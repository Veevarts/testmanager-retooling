## General survey → after-login only (code + unit tests)

Feature flag (lib/surveyDisplayRules.ts:5):
  export const GENERAL_FEATURE_TRIGGERS_ENABLED = false;

Guard function (lib/surveyDisplayRules.ts:7-9):
  export function supportedGeneralSurveyDeliveryMode(mode: GeneralSurveyDeliveryMode): GeneralSurveyDeliveryMode {
    return GENERAL_FEATURE_TRIGGERS_ENABLED ? mode : "afterLogin";
  }

Consumption in SurveysPage.tsx:325-327:
  generalDeliveryMode: s.isGeneralSurvey
    ? supportedGeneralSurveyDeliveryMode(parsedTriggerDetails.generalDeliveryMode)
    : parsedTriggerDetails.generalDeliveryMode

Effect: even if legacy data has `generalTrigger=featureTrigger` (e.g. Survey #2
"QA TC-143 · org-scoped · feature-trigger" in dev), when loaded into the edit
form it is forced back to afterLogin.

## Required delay validation

lib/surveyDisplayRules.ts:110-112:
  if (input.isGeneralSurvey && input.generalDeliveryMode === "afterLogin" &&
      !isValidOptionalNonNegativeInt(input.loginDelaySeconds ?? "")) {

required + unit tests cover all 4 negative branches).
