### A03 · Injection — Applicable, PASS
The SQL diff is 2 ON-clause modifications from `mt.MEMBERSHIPLEVELID = ml.ID` to
`COALESCE(soim.MEMBERSHIPLEVELID, mt.MEMBERSHIPLEVELID) = ml.ID`. Both operands are static
column references (no parameters, no string concatenation, no user input). safesql runs the
query read-only through parameterized mssql driver.
Verdict: PASS.

### A04 · Insecure Design — Applicable, PASS
The redesign strengthens integrity: the pipeline now reads the level/term the sale actually
carried rather than a mutable transaction field. The COALESCE keeps the previous behavior for
the 84% of MTs without a sales-order line (fallback intact). No new failure mode introduced;
the whole class of "silent wrong-program" bugs is eliminated for the 16% of MTs with a
sales-order line.
Verdict: PASS.
