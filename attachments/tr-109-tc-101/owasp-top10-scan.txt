OWASP Top 10 (2021) applicability scan — PR Veevarts/MigrationToolETL#145
==========================================================================

Change surface: 2 static SQL files (SELECT-only) + 1 static test contract. Runtime
target is a customer's restored Altru SQL Server backup (read-only) → CSV → SF
bulk upsert (existing loader, unchanged).

| Cat  | Category                                     | Applicable? | Verdict | Notes |
