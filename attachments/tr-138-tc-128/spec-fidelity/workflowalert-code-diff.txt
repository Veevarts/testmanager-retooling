    step + handoffs" to 1 MANUAL handoff (OWEA create+verify) + 3 AUTOMATED steps.
    
    New reusable T3 op `workflowAlert` (catalog-declarative, zero per-IC code):
    sets senderType=OrgWideEmailAddress + senderAddress on named Email Alerts and
    appends recipients, via the synchronous CRUD Metadata API. Proven live on
    CamiloDevOrg that a MANAGED WorkflowAlert is subscriber-configurable: adding a
    user recipient to the managed Auctifera Error Log alert commits and reads back;
    setting the OWEA sender passes managed-protection and reaches Salesforce's
    "must be a verified Org Wide Email Address" validation. The OWEA is resolved
    DYNAMICALLY from the OrgWideEmailAddress sObject by the operator-supplied
    address/displayName (never hardcoded) and required verified, so part 4 depends
    on the manual OWEA step; absent alerts and blank optional recipients are
    tolerated.

      recipient on the Error Log alert.
