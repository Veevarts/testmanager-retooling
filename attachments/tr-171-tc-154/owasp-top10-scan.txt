### A03 · Injection — Applicable, PASS
The SQL diff has no new user-input params or string concatenation into SQL. safesql runs the
query read-only through parameterized mssql driver. The 6-deep REPLACE nest is client-side HTML
escaping for a rich-text target field — it prevents HTML injection from note content into
Salesforce's rich-text sanitizer. Static spec pins the escape order (& first, then < and >, then
newlines); if reverted, a note reading "Setup <see contract> by 8am" would lose "<see contract>"
to Salesforce sanitization, and multi-line notes would collapse to one line.
Verdict: PASS.

over another. Row grain preserved by pre-aggregating ItineraryItem via CTE (no fan-out).
Documented cosmetic edge (leading/trailing newline → bare <br>) is accepted per SQL 2017 version
floor and does not compromise integrity.
