Escenario 8 — convertir algo que ya no es sugerencia falla cerrado
===================================================================

  accion                                        | HTTP | respuesta
  ----------------------------------------------|------|---------------------------------
  convertir una fila que ya se convirtio        | 409  | "Invalid task transition:
  (segunda vez sobre la misma)                  |      |  New → New. Allowed from New:
                                                |      |  [In_progress, Done, Rejected]."
  convertir una sugerencia declinada            | 409  | "Task 558cb09f-... is deleted;
                                                |      |  restore it before changing its
                                                |      |  state."
  ----------------------------------------------|------|---------------------------------
  preparacion y limpieza del caso anterior:
  decline sobre la sugerencia restante          | 201  | state = Rejected
  restore para devolver el entorno              | 201  | state = Suggested

  Los dos rechazos llegan con el motivo y con la salida: el primero enumera las
  transiciones que si son validas, el segundo dice exactamente que hacer antes.
  Ningun 500, ningun 200 silencioso. Los conteos del panel y de la lista de tareas quedaron
  consistentes despues de los rechazos, y la sugerencia usada para la prueba volvio al
  panel.
