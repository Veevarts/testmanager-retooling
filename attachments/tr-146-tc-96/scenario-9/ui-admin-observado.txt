IMPORTANTE — CORRECCIÓN DE ETIQUETAS
El paso a paso original de este escenario usaba los labels que aparecen en el CÓDIGO
(`<option value="everyone">Everyone</option>` / `Organization / museum`). La UI REAL renderiza
otra cosa para una General: son RADIOS, no un select, y el texto es distinto. Corregido en el
test case con lo observado:

  CÓDIGO decía                     UI REAL muestra
  ------------------------------   --------------------------------------------
  select "Audience"                bloque "To whom are you sending this survey?"
  opción "Everyone"                radio  "To everyone"
  opción "Organization / museum"   radio  "To an organization / museum"
  botón "Save"                     botón  "Create"

OBSERVACIONES VERIFICADAS EN PANTALLA

1. Toggle "General NPS survey" .................................................. CONFIRMADO
   Al marcarlo aparece el bloque "General survey trigger" con dos radios:
       (•) Show through existing feature triggers      <- MARCADO POR DEFECTO
       ( ) Show after login
   Dato útil para el equipo: una General nueva nace en modo feature-trigger.
   Evidencia: 00-before-general-toggle.png / 01-general-required-label.png

2. Etiqueta dinámica del campo de audiencia ..................................... CONFIRMADO
   Con la survey marcada como General, el bloque muestra literalmente:
       "Audience details (required)"
       "Selected organizations become the client org audience for the general survey."
   Evidencia: 01-general-required-label.png

3. Validación en el navegador con lista de organizaciones vacía ................. CONFIRMADO
   Con "To an organization / museum" seleccionado y ninguna organización elegida, al pulsar
   "Create" el formulario NO se envía y aparece en pantalla:
       "Please choose at least one organization / museum for this general survey."
   El formulario permanece abierto. La petición no sale a la API: es el espejo en UI del 400
   que el AC2 exige del lado servidor.
   Evidencia: 02-validation-empty-orgs.png

4. Cómo se ve un scope global en el listado ..................................... CONFIRMADO
   La General activa (id 17, audience=everyone) se lista como:
       "General survey audience: All active organizations"
   Es la expresión visible del AC3.
   Evidencia: 03-list-all-active-orgs.png

5. Campos adicionales del formulario observados (contexto para el equipo):
   "Show after User.CreatedDate" · "When to show it" · "Start Date" ·
   "After a specific number of interactions" / "Immediately on the first eligible interaction" ·
   "Repeat window" (One time / Monthly 30 / Quarterly 90 / Semiannual 180 / Annual 365 / Custom) ·
   "Max dismissals per period" · "Tries between shows" · "Max shows per day" ·
   "Active (shown to respondents)"
