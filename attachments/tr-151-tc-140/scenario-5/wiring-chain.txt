CAVEAT — what this scenario does and does not prove.
It proves the object is wired so that a run WILL pick it up. It does not prove rows landed in a
target org, because that requires an actual Migration App run against an org, which QA did not
perform here (no org in scope for this PR, which is source-side only). The source-side proof that
the rows exist is scenario 1/3: the query emits 79327 rows on tucson. The AC's phrase "actually
exported" is therefore covered at the query + wiring level, not at the org level.
