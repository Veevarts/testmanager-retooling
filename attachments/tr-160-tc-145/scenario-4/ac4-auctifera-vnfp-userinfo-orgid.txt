## LWC widget — passes it in every request to Survey Tool

Both Auctifera and NFPFundraising npsWidget.js:

  import getOrganizationId from "@salesforce/apex/NpsWidgetController.getOrganizationId";
  ...
  @wire(getOrganizationId)
  wired({ error, data }) {
    if (data) this._organizationId = data;
    else this._organizationId = "";
  }
  ...
  get resolvedSalesforceOrgId() {
    return (this.salesforceOrgId || "").trim() || (this._organizationId || "").trim();
  }
  ...
  async fetchEligibleSurveys(...) {
    const params = new URLSearchParams({
      clientOrgId: payload.clientOrgId,
      salesforceOrgId: payload.salesforceOrgId,  // <-- AC4 evidence
      ...
    });
    const url = `${this.normalizedBaseUrl}${path}?${params.toString()}`;
    const response = await fetch(url, { method: "GET" });
  }

Impressions + dismissals + open events all include `salesforceOrgId: this.resolvedSalesforceOrgId`
in the POST body (npsWidget.js lines 256-257, 326-327, 384-385 in Auctifera; equivalent
in NFPFundraising).

## Static-resource fallback (SurveyWidgetTrigger.js)

Both packages ship a standalone JS trigger that ALSO propagates salesforceOrgId when the
caller provides it (SurveyWidgetTrigger.js line 18 + 34). This is the non-LWC path used
by aura and utility bar embeddings.
