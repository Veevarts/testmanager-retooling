Notes:
  · The 22 "secret pattern" matches in the survey-tool #38 diff are all false positives: they are:
      - `Authorization: Bearer ${accessToken}` (HTTP header building for SF OAuth, standard pattern);
      - `process.env.SURVEY_TOOL_ENV / APP_ENV / NODE_ENV` (env-var references in tests);
      - `.environment()` (API method call, unrelated).
    No hardcoded credentials found in any diff.
  · A02 is a PASS because although salesforce-config.json contains plaintext secrets on disk,
    it's never served via any endpoint and the response DTO strips them. In a container/Fargate
    deploy, ephemeral filesystem is acceptable; long-term the recommendation is to move these
    secrets to AWS Secrets Manager or Parameter Store, but that's a follow-up, not a blocker.
