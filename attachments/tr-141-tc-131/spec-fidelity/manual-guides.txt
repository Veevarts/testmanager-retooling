=== step 2 Set up the Company Information Lightning page (MANUAL) — actions=4 estMin=6 ===
context: Salesforce has no API to add a managed component to a managed Lightning page or to set an org-default record page, so do this by hand in the org and mark it done.
  1. In Setup → Object Manager → Company Information, open the Lightning record page in the Lightning App Builder (Edit Page).
  2. From the right ‘Add Components Here’ region, search the palette for ‘Manage Files’ and drag it onto the page.
  3. In the component properties, set Lookup field name to Auctifera__Company_Information__c and Height to 200px, then Save.
  4. Click Activate → Assign as Org Default → select Desktop and phone → Next → Save.

=== step 3 Upload the company logo (MANUAL) — actions=3 estMin=3 ===
context: Upload the museum logo on the Company Information record using the Manage Files component you just added.
  1. Open the primary Company Information record.
  2. In the ‘Manage Files’ component, drag or upload the museum logo into the ‘Drop a file here’ area (upper-right).
  3. Confirm the logo appears on the record.

=== step 4 Add two fields to the Veevart File layout (MANUAL) — actions=4 estMin=5 ===
context: The Veevart File layout is part of a managed package, so the Metadata API cannot change it — add the two fields by hand on the active layout.
  1. In Setup → Object Manager → Veevart File → Page Layouts, use Page Layout Assignment to find the currently assigned layout and open it.
  2. Add the ‘Specific Fund Banner’ field to the layout.
  3. Add the ‘Membership Card Logo’ field to the layout.
  4. Save the layout.

=== step 6 Set the fiscal year in Setup (MANUAL) — actions=4 estMin=5 ===
context: The fiscal year start month is read-only via the API, so set it in Setup. In Salesforce the fiscal year is identified by its START month and starts the month AFTER it ends.
  1. In Setup, Quick Find ‘Fiscal Year’ → Company Settings → Fiscal Year.
  2. Set the Start Month to the month after the fiscal-year end month from the kick-off (ends August → starts September; ends December → starts January).
  3. Set ‘Fiscal Year Is Based On’ to the ending month.
  4. Save and confirm the recalculation warning.
