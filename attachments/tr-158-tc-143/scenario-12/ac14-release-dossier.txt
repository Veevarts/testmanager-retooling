2. 20 new console.log statements in NFPFundraising #2234 across
   BoxMembershipDonationHelper.js (+1), JournalEntryUpdateController.js (+1),
   PaymentAssignmentHelper.js (+1), PaymentController.js (+2), PaymentHelper.js
   (+4), ExhibitionWizardHelper.js (+4), and the new npsWidget.js (+7). None
   are functional bugs; they are noise-in-prod-devtools. Recommend stripping
   before merge OR wrapping behind a debug flag.

   case (`00DEm00000V5eRWMAZ`). Current release normalizes at the launcher, so
   no data is lost today, but downstream consumers passing the raw Id will get
   empty reads unless they lowercase first (or the server compares
   case-insensitive).

   `audienceDetails` and `GSI1SK`. For an org-scoped survey this exposes the
   targeted organization id to any anonymous client that guesses the context.
   TR-157 called this Sev Low; no change today. Re-report only.
