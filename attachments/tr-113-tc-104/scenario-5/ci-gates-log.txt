    message that the wait strategy needs.

    takes ~90-120 s to reach "Started".
  - The dev's CI (Linux runner, native amd64) has no such wait; PR body attests
    `22 passed` for this suite.

Verdict: The 4-suite docker run is BLOCKED locally by an environment timeout,
not a code defect. Dev's CI is the source of truth for this test's pass count
(22/22 per PR body).
