------------------------------------------------------------------------------
CDK stack: infra/lib/survey-tool-stateful.stack.ts
------------------------------------------------------------------------------

Defines 5 DynamoDB tables via `dynamodb.Table` construct:

| id                   | app            | logical name                 | GSIs (from data model) |
| -------------------- | -------------- | ---------------------------- | ---------------------- |
| SurveysTable         | surveys        | survey-tool-surveys          | GSI1, GSI2             |
| ResponsesTable       | responses      | survey-tool-responses        | GSI1, GSI2, GSI3, GSI4 |
| RespondentStateTable | respondent-state | survey-tool-respondent-state | GSI1 (TTL: expiresAt)  |
| OrganizationsTable   | organizations  | survey-tool-organizations    | GSI1, GSI2             |
| SettingsTable        | settings       | survey-tool-settings         | (none)                 |

Common properties on every table:
  · partitionKey: PK (STRING)
  · sortKey: SK (STRING)
  · billingMode: PAY_PER_REQUEST
  · pointInTimeRecoverySpecification: enabled iff envName in {prd, stg}
  · deletionProtection: enabled iff envName in {prd, stg}
  · removalPolicy: RETAIN for prd|stg, DESTROY for dev|eph

10 stack-level tags applied via `Tags.of(stack).add()`:
  organization, product, domain, service, environment, region, team, tool,
  release, stack_type

Plus per-table tags:
  logical_resource_name, description

Table name + ARN exported as CfnOutput per table (SurveysTableName/Arn,
ResponsesTableName/Arn, etc.) — feeds a stateless stack.

Vitest coverage: infra/test/survey-tool-stateful.stack.spec.ts (141 lines, 6 tests)
------------------------------------------------------------------------------

Tests exercise `cdk.Template.fromStack(synth())` and assert:

1. `provisions the five DynamoDB tables with PK/SK and on-demand billing`
   → `resourceCountIs('AWS::DynamoDB::Table', 5)`
   → `hasResourceProperties: KeySchema PK HASH + SK RANGE, BillingMode PAY_PER_REQUEST`

2. `adds the access-pattern GSIs required by the app views`
   → SurveysTable: GSI1, GSI2 present
   → ResponsesTable: GSI1, GSI2, GSI3, GSI4 present
   → RespondentStateTable: TTL on `expiresAt` + GSI1 present

3. `retains and protects every prd/stg table` (parametrized on ['prd', 'stg'])
   → DeletionPolicy=Retain, UpdateReplacePolicy=Retain,
     DeletionProtectionEnabled=true, PointInTimeRecoveryEnabled=true

4. `exports every table name and ARN for application stacks`
   → 10 CfnOutputs present (5 names + 5 ARNs)

5. `rejects unsupported environment aliases before synthesis`
   → `parseVeevartEnv('prod')` throws; `parseVeevartEnv('qa')` throws;
     `parseVeevartEnv(undefined)` = 'dev'; `parseVeevartEnv('prd')` = 'prd'

6. `applies stack suffixes to ephemeral and dev resource names`
   → suffix accepted for eph/dev; naming shape matches
